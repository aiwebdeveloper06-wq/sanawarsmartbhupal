# Sanawar Smart School Bhupal, Mansa (Punjab) — Official Website

Complete, production-ready luxury institutional website redesign for **Sanawar Smart School Bhupal, Mansa, Punjab** (CBSE Affiliation No. `1631322`, School Code `21360`), built using pure **HTML5**, **Bootstrap 5.3**, **CSS3**, and centralized **Vanilla JavaScript** (`assets/js/main.js`).

## Technology Stack

- **HTML5**: Semantic institutional markup across all 47 standalone pages (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **Bootstrap 5.3**: Responsive grid system, navigation bar, dropdowns, carousel, tabs, and responsive tables.
- **CSS3 (`assets/css/style.css`)**: Custom luxury color palette (`#071A2B` Deep Navy, `#173B8F` Royal Blue, `#18C8D4` Sky Cyan, `#E6B84A` Warm Gold, `#D62839` Deep Red, `#F8FAFC` Light Canvas, `#FFFFFF` Pure White) and editorial typography (`Playfair Display` + `Manrope`).
- **Vanilla JavaScript (`assets/js/main.js`)**: Centralized script limited strictly to sticky header scroll state, scroll-triggered entrance reveal animations, active navigation link highlighting, and form submission feedback.
